# Выпуск урока: файл Натэлы → Kinescope + обложка + скриншоты + конспект → буфер

Один конвейер, восемь шагов. Каждый повторяемый шаг — скрипт в `scripts/`, запускать
**системным `python3`** (в нём PIL, requests, playwright; в venv «Повторяемой задачи» PIL нет).
`--course` можно не передавать, если cwd внутри папки курса. Константы курса — проект Kinescope,
префикс CSS, папки, эталон конспекта — в `courses.yaml`; новый курс = новая запись там, скрипты
не трогаем. `--help` у каждого скрипта.

## Точка истины

Итоговый файл Натэлы (`~/Downloads/<Курс> N.N.mp4`), **не** рендер монтажа: после монтажа она
режет паузы, и тайминги `SHOT-LIST`/`rech.txt` сдвинуты. Конспект и база знаний — по расшифровке
итогового файла (шаг 2). Исходник в Загрузках не трогаем.

## Порядок (не переставлять)

0. **Опознать.** Курс (`courses.yaml`), урок N.N, файл в Загрузках, папка урока
   `производство/уроки-МN/N.N-<slug>/` — нет → создать: slug = 1–2 слова темы транслитом, как у
   соседей (`2.2-polka`, `1.9-kontrolyor`); скрипты берут первую папку `N.N-*`, переименовать
   можно до заливки скриншотов. Папка монтажа `Монтаж/output/<…>` — может отсутствовать (урок снят
   без нашего монтажа): тогда шаг 2 идёт без сверки, кадры на шаге 5 — из итогового файла.
   `ffprobe` длительности файла и рендера — разницу объяснит шаг 2.
1. **Пережать.** `cd Монтаж && .venv/bin/python scripts/compress_video.py --codec h264 --crf 21 "<файл>"`.
   Скрипт предупредил «битрейт уже низкий» (рендер монтажа ~0,6 Мбит/с) → **не пережимать**, заливать
   как есть. Результат переименовать в `<Курс> N-N.mp4` рядом с исходником и открыть Натэле:
   `open -a "QuickTime Player" "<файл>"`.
2. **Расшифровать итог и сверить с монтажом.**
   `python3 scripts/transcribe_final.py --lesson N.N --file "<исходник>"` → `final/transcript_final.json`,
   `rech_final.txt`, вердикт «вырезаны только паузы» или список вырезанных кусков — их в конспект не брать.
3. **Kinescope.** `python3 scripts/kinescope_upload.py --lesson N.N --file "<N-N.mp4>"` → `short_id`
   (для embed и реестра), uuid, items_count +1, транскод done, 1080p. Не +1 → найти и удалить
   мусорную запись (`--status`, API).
4. **Обложка.** Текст — голос Натэлы: сначала Skill `natela-style`, затем `natela-tone-of-voice`.
   Заголовок ≤ 22 знаков называет тему урока (внутри курса обложка не продаёт), подзаголовок ≤ 80.
   `python3 scripts/cover.py --lesson N.N --video-id <short_id> --title "…" --sub "…"` → пара
   одежда+поза берётся из незанятых сама (`--pairs` — посмотреть), портрет через Визуал, рендер,
   постер на Kinescope, снимок плеера. **Посмотреть `проверка/player_N.N.png` глазами:** кнопка
   «плей» не на буквах, деловой casual, рукава подвёрнуты, левая половина без текста-мусора.
5. **Скриншоты.** Источник — размеченные кадры монтажа `Монтаж/output/<урок>/screencasts/flat/*.png`
   (без `_ov`) и `raw/`; нет их — кадры из итогового файла (`ffmpeg -ss T -i <файл> -frames:v 1 -q:v 2 k.png`)
   плюс рамка/лупа через `Монтаж/scripts/annotate_shot.py` (экран целиком, крупность — врезкой).
   Отобрать 18–30 кадров по ходу речи, назвать `<prefix>NN-slug.png|jpg` (prefix из `courses.yaml`,
   напр. `vm22-`), сложить в отдельную папку, затем:
   `python3 scripts/shots_upload.py --lesson N.N --from <папка> --contact-sheet --dry` → посмотреть
   контактные листы на личные данные (чужие ФИО, телефоны, почты, чаты → замазать; своё Натэла
   показывает) → `python3 scripts/shots_upload.py --lesson N.N` → `скриншоты/_src/gc_urlmap.json`.
   Поле загрузки не появилось → сессия админки протухла: сказать Натэле, нужен свежий вход.
6. **Конспект.** (а) Skill `natela-style` → `natela-tone-of-voice` — блокирующий шаг перед текстом.
   (б) Открыть эталон (`konspekt_etalon` в `courses.yaml`): CSS берётся оттуда с заменой префикса,
   структура — та же. (в) Писать **по видео** (`rech_final.txt`) голосом Натэлы по
   `references/konspekt-checklist.md`; картинки относительными `src="скриншоты/<prefix>NN-slug.jpg"`.
   (г) `python3 scripts/apply_urls.py --lesson N.N`.
   (д) **Сверка обещаний видео — сам, не по отчёту того, кто писал конспект** (правило Натэлы 16.09.2026).
   Всё, что в речи «лежит под уроком / на листке / обещала / в следующий раз», обязано реально лежать
   в конспекте, а «под уроком» — ещё и строкой в блоке ссылок под видео. `check_konspekt.py` сам выписывает
   эти места из `rech_final.txt`; по каждому открыть конспект, найти, записать строку в
   `<папка урока>/ОБЕЩАНИЯ-ВИДЕО.md` (время · что сказано · якорь · дословный кусок текста; образец —
   `бонус-сервер/b6-telefon-vmesto-stola/`). Не нашлось — дописать в конспект, а не в таблицу.
   Без файла, с несверенным местом, с куском не в секции якоря или без ссылки под видео — жёсткая ошибка.
   (е) `python3 scripts/check_konspekt.py --lesson N.N`
   → чинить до «ЖЁСТКИХ ОШИБОК НЕТ», рендеры `_src/render_*.png` посмотреть глазами.
   (ж) Сверка с соседними уроками — раздел чек-листа. (з) `pbcopy < КОНСПЕКТ.html && pbpaste | wc -c`.
7. **Журналы курса** (пути в `courses.yaml`, шаблоны четырёх записей — `references/zhurnaly.md`):
   реестр Kinescope — строка в таблицу модуля + абзац заливки; карта уроков — строка урока;
   журнал «где мы остановились» — запись сверху: сделано, id заготовки на платформе, что осталось;
   **реестр уроков** (`РЕЕСТР-УРОКОВ.md`) — статус урока в карточке + строка в очереди М-модуля +
   счётчики в сводной таблице (правило Натэлы 26.08.2026: реестр всегда актуален).
8. **Отчёт Натэле:** ссылка Kinescope, строка «обещаний в видео N — все закрыты» (из `ОБЕЩАНИЯ-ВИДЕО.md`), что лежит в буфере, куда вставлять (id заготовки; блока нет —
   новый «Блок: HTML»; JS-блок mze6 последним; комментарии к уроку выключены), что осталось.
   **База знаний — только после её «принято»:** «Кратко» и тезисы пишет Claude по видео (образец —
   `Монтаж/output/vaib-2-2/final/kratko.md`, `tezisy.md`), затем
   `python3 scripts/kb_export_lesson.py --lesson N.N --summary-file … --theses-file … --topics "…"`.

9. **Прибраться на диске — после «принято» от Натэлы.** Урок лежит на Kinescope, ссылка в реестре —
   локальные копии больше не нужны и молча съедают диск (сентябрь 2026: так набралось 178 ГБ дублей).
   Проверить перед удалением, иначе останемся без мастера: `--status <short_id>` показывает транскод
   `done` **и качество 1080p** — только 720p значит, что залили пережатую версию, тогда сначала
   перезалить мастер (`kinescope_upload.py --replace <short_id>`, id и ссылки сохраняются).
   Сошлось — в Корзину (не `rm`, сутки на откат) итоговый файл из Загрузок, пережатую копию рядом
   и `Монтаж/input/<урок>/` с исходниками съёмки, **а также сырые записи начитки и скринкастов**, откуда бы
   их ни взяли (`~/Movies/<дата время>.mp4`, дозаписи хвостов — путь есть в памяти/журнале урока): после
   выпуска они не нужны (правило Натэлы 25.09.2026). **Оставить:** `Монтаж/output/<урок>/` без видео —
   `SHOT-LIST.md`, расшифровки, размеченные кадры `screencasts/`: по ним пересобирается конспект.
   Мастер удаляем только когда на Kinescope лежит равное качество — оригинал оттуда не выгружается,
   API отдаёт лишь транскод.

## Что параллелить

Пережатие, расшифровка и портрет для обложки независимы — запускать фоном сразу. Заливка ждёт
пережатия; постер ждёт `short_id`; конспект ждёт расшифровку и карту URL. Пока крутится фон —
выбирать кадры и писать текст обложки.

## Границы

- Не монтирует видео → `montage`. Не вставляет блок и не создаёт уроки в админке → Натэла руками;
  точечные правки живого блока → `производство/оформление-getcourse/gc/gc.py` (pull → дифф → push).
- Не выгружает в базу знаний до приёмки и не пишет от себя того, чего нет в видео.
