# Чек-лист конспекта урока (самодостаточный «Блок: HTML» под GetCourse)

Эталон структуры и CSS — `konspekt_etalon` из `courses.yaml` (Вайбкодинг: `2.2-polka/КОНСПЕКТ.html`,
до него — `1.9-kontrolyor`, `1.13-priberemsya`). CSS копируется целиком с заменой префикса
(`vm22-` → `vm23-`), тело пишется заново по видео.

## Скелет (в этом порядке)

1. **Комментарий-шапка** в начале файла: урок, точка истины (файл, длительность), Kinescope id,
   что вырезано из начитки, какой термин вводится, что сверено с соседями.
2. **Hero:** brand-strip «Нейрокомбайн 2.0 · Вайб-кодинг · Модуль N», h1 с золотым акцентом —
   крючок из первой минуты видео; подзаголовок 4–6 строк голосом; 3 плашки-меты (формат и
   хронометраж, «ни одной команды/строчки кода», сколько займёт у ученика).
3. **Оглавление ДО первого видео** («Про что урок»): якоря `#<prefix>id` на каждую секцию, бейджи
   `Видео` / `Главное` / `Термин` / при развилках `Путь А/Б`; заметка «если времени в обрез — пункты …».
4. **Секция видео:** iframe `https://kinescope.io/embed/<short_id>` + **блок ссылок сразу под видео**:
   все внешние ссылки урока (`target="_blank" rel="noopener"`, промокод текстом рядом) + якоря на
   каждую «рамку под видео», которую Натэла обещала в речи (фразы для копирования, напоминалки).
   Внешних ссылок нет — так и написать одной строкой. Закрыть строкой «вопросы — в чат курса,
   кураторы рядом» (без адреса чата).
   **Проверяется, а не пишется на глаз:** каждое «лежит под уроком» из речи — строкой в
   `ОБЕЩАНИЯ-ВИДЕО.md` с якорем и дословным куском; `check_konspekt.py` без этого не проходит (SKILL.md, шаг 6д).
5. **Секции по ходу видео**, чередуя фон (`-alt`): тег-плашка → h2 → lead → текст → кадры
   (`figure` + figcaption с мыслью, а не подписью «скриншот»). Инструменты: `formula` (мысль-якорь с
   золотым акцентом), `note` (врезка «Я вам это обещала» / «чтобы не осталось тревоги»), `term`
   (карточка нового термина: образ один раз, дальше сам термин), `skills` (пронумерованные шаги),
   `two`/`box` (`-good` спокойное, `-warn` предостережение), `cards` (карта из 3–5 понятий),
   `p.<prefix>mono` (фраза для копирования — блочная, переносится).
6. **«Что забрать из этого урока»** — абзац-итог + список `take` 6–9 строк + финальная `formula`.
7. **«Ваш ход»** (тёмная секция `next`): что сделать руками, фразы в рамках, «Если что-то пошло не
   так» (ветки по инструментам Claude Code / Codex / Kimi Code там, где поведение различается;
   каждая беда → готовая фраза нейросети; «не бейтесь дольше пятнадцати минут — скриншот целиком
   в чат курса, кураторы рядом»), «Напишите в чат…» (показать своё · спросить · помочь отставшему).

## Язык и голос

- Голос Натэлы (скиллы `natela-style` → `natela-tone-of-voice` прочитаны до текста, 2–3 поста из
  корпуса перечитаны). Рассказ, не методичка; страшные места (деньги, «не вышло», риск) — без шуток.
- Всегда на «вы». «Нейросеть» (ж. р.) — та, с кем разговаривают; «агент» — то, что она собирает;
  «шпаргалки (skills)»; «финансовый помощник» — имя системы, не синоним нейросети.
- Термин вводится один раз через образ, дальше ведём сам термин (репозиторий/полка, контекст/стол).
- Нет: номеров уроков/модулей в речи («прошлый урок», не «урок 1.3»), «вчера/сегодня» (ученик
  смотрит подряд), «ИИ», «сессия», «тест», CAPS, `!!!`, «легко/без усилий/гарантирую», инфобизнес-жаргона,
  «не пугайтесь», «это никто не проверяет», обещаний «отвечу лично».
- Mac первым, Windows в скобках — если различается. Кнопки называть по функции, не по цвету.

## Честность

- Видео = точка истины: расхождение начитки и видео → по видео; чего в видео нет — в конспекте
  нет как «сказанного». Своё от конспекта (напоминалка, ветка Codex) — без ссылки на «в видео я сказала».
- Обещания соседям: закрыть то, что предыдущие уроки обещали про этот (врезка «Я вам это обещала»);
  вперёд обещать только то, что есть в программе и в видео («в конце модуля поставите свою»);
  свойства инструментов — только после факт-чека.
- Деньги, суммы, «больше не спишут» — слово в слово одна рамка со всеми уроками курса.
- «Напишите кураторам» без адреса. Аварийный выход и кнопка отката у каждой ошибки.

## Сверка с курсом (перед сдачей, grep по папкам уроков)

1. Обещания туда-обратно: что соседи обещали про этот урок и что этот говорит про соседей.
2. Термины: не переопределять уже введённые (контролёр, субагент, репозиторий…), не занимать
   образы будущих уроков.
3. Числа, названия папок (`NeuroCombine`), сервисов, кнопок, файлов — как в предыдущих уроках.
4. Правила курса: VPN не выключаем, кураторы без адреса, границы данных, юр-рамка.
5. Результат сверки — строкой в журнал курса.

## Техника

- Самодостаточный блок: один `<div class="<prefix>root">`, стили внутри, без внешних CSS/JS и шрифтов
  (Montserrat/Open Sans — из темы школы), `src` абсолютные `https://fs.getcourse.ru/…` после
  `apply_urls.py`, префикс только свой.
- Тема GetCourse перебивает `padding` у ссылок в `.gc-main-content` → кнопки-ссылки с
  `!important` и для `:link/:visited`; `&nbsp;` и HTML-сущности сервер раскодирует — не полагаться.
- `check_konspekt.py` без жёстких ошибок; рендеры 1440/390 просмотрены; `voice-lint` — 0 находок,
  кроме капслока имён файлов и служебных комментариев.
