## 4. Реестр уроков (`РЕЕСТР-УРОКОВ.md`, корень курса) — правило Натэлы 26.08.2026: всегда актуален

Реестр отвечает на «о чём · какой навык · в каком состоянии» и обновляется **на каждом переходе
статуса**, не только при выпуске: ✍️ написан (начитка принята цехом) → 🎬 снят / смонтирован →
✅ на платформе (после вставки Натэлой и сверки `gc.py pull` с мастером). Три места правки:

1. **Карточка урока** (`### N.N · Название`) — строка `- **Статус:**` целиком, по образцу:
   ```
   - **Статус:** ✅ снят DD.MM · смонтирован и выпущен DD.MM · Kinescope `<short_id>` · **залит** — блок `<block id>` в `<lesson id>`, совпадает с мастером (сверено DD.MM)
   ```
   Промежуточные формы: `🎬 … смонтирован DD.MM `<путь mp4>` — ждёт приёмки Натэлы · 🗒 `<lesson id>` пуста`;
   `✍️ начитка ред. N (вердикт ученика «да»), не снят · 🗒 …`. Хронометраж в строке «Формат» —
   смонтированный, не программный, как только видео есть.
2. **Очередь производства модуля** (раздел 2 для М2; для следующих модулей — завести такой же
   раздел при старте производства): колонка «Состояние», следующий урок пометить «⬜ следующий к
   съёмке», закрытые блокеры из «Что нужно до съёмки» убрать, новые — добавить.
3. **Сводная таблица «Курс целиком»** (раздел 1): счётчики ✅ / 🎬 / ✍️ / ⬜ по модулю.

В шапке реестра дата «Собран …» не меняется; при правке дописывать «обновлён DD.MM» в ту же строку.
