# vypusk-uroka — скилл Claude Code «Выпуск урока»

Конвейер выпуска готового видеоурока на платформу: итоговый файл → пережатие → расшифровка →
Kinescope → обложка → скриншоты в GetCourse → конспект (самодостаточный HTML-блок) → код в буфер →
журналы курса → после приёмки база знаний и уборка диска.

Вход — `SKILL.md` (порядок шагов), детали — `references/` (чек-лист конспекта, грабли, шаблоны журналов),
повторяемые операции — `scripts/` (системный `python3`, `--help` у каждого).

## Важно перед использованием

Скилл собран под конкретную рабочую среду и без настройки не заработает. Он опирается на:
- отдельные проекты «Монтаж» (пережатие, расшифровка), «Визуал» (портреты для обложек), CLI базы знаний;
- скиллы голоса автора (`natela-style`, `natela-tone-of-voice`);
- свой аккаунт Kinescope и свою школу на GetCourse.

`courses.yaml` — шаблон: заполните своими значениями. Ключ Kinescope и сохранённый вход в GetCourse
хранятся **вне** репозитория (пути указываются в `courses.yaml`) — не коммитьте их.

Пути вида `~/Documents/My_agents/...` и `Курсы/.claude/skills/` — раскладка автора, поменяйте под свою.
